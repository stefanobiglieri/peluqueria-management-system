# Sistema de Gestión para Peluquerías

Versión actual: **0.1.0-alpha**

> Proyecto académico y profesional desarrollado desde cero siguiendo las etapas de la Ingeniería de Software.

---

## Descripción

El Sistema de Gestión para Peluquerías es una aplicación web responsive orientada a la administración integral de peluquerías y barberías.

Su objetivo es permitir la gestión de turnos, servicios, empleados, clientes, pagos y estadísticas mediante una plataforma moderna, intuitiva y segura.

El proyecto está siendo desarrollado siguiendo un proceso completo de Ingeniería de Software, documentando cada una de sus etapas, desde el análisis de requisitos hasta su implementación y despliegue.

---

## Objetivos del Proyecto

- Aplicar buenas prácticas de Ingeniería de Software.
- Desarrollar una arquitectura escalable y mantenible.
- Implementar una API REST utilizando FastAPI.
- Construir una interfaz web responsive utilizando React.
- Gestionar información mediante PostgreSQL.
- Aplicar Programación Orientada a Objetos y arquitectura por capas.
- Mantener un control de versiones profesional mediante Git y GitHub.

---

## Funcionalidades previstas

### Administración

- Gestión de usuarios.
- Gestión de peluqueros.
- Gestión de clientes.
- Gestión de servicios.
- Gestión de horarios disponibles.
- Gestión de turnos.
- Cancelación de turnos.
- Reportes y estadísticas.
- Control de ingresos.

### Peluqueros

- Administración de agenda personal.
- Configuración de horarios disponibles.
- Gestión de servicios ofrecidos.
- Confirmación y cancelación de turnos.
- Consulta de estadísticas personales.

### Clientes

- Consulta de turnos disponibles.
- Reserva de turnos.
- Pago online.
- Confirmación automática de reservas.
